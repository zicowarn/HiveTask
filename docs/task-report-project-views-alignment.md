## 关键修复（根因备忘）

1. **折叠组间无 12px 间隙（十轮未解）**：间隙载体挂在"展开态才渲染的添加行 border-bottom"上，
   折叠组没有添加行 → 间隙消失。修法：载体改为**每组最后一个可见行**（展开组 = 添加行、
   折叠组 = 组头自身 `--collapsed`）。
2. **添加行偏矮**：`border-collapse` 下相邻行 `border-top` 会向上叠进上一行白盒（最小复现实测
   啃掉 13px）；全局 `box-sizing: border-box` 下 12px border 又计入行盒内部；按钮 `inline-flex`
   基线 strut 再撑高 6.5px。修法：`border-bottom` 载体 + td 显式补高（38 白区 + 12 灰隙）+
   按钮改块级（`flex + fit-content`）。
3. **Roadmap 今日红线过长**：以条目区容器（`rm-lanes`，`position: relative; flex: none`）为定位
   参照，红线 `top:0 → bottom:0` 恰好止于表格收口线，不越过收口线/灰带。层序：灰底网格(z0) <
   红线(z1, `--danger` 30%) < 条目行(z2)——红线从卡片背后穿过。
4. 沉淀的通用教训（flex-shrink 压扁、grid 困住 sticky、static 被定位层遮盖等）见各提交说明。
